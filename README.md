# sgd-tibu-udes
Sistema de Gestión Documental para las partidas sacramentales de la Diócesis de Tibú. Proyecto de grado de Ingeniería de Sistemas de la Universidad de Santander (UDES). Desarrollado con React, FastAPI y PostgreSQL. Incluye gestión documental, certificados, usuarios, roles, auditoría y trazabilidad.
