# Dirección visual del archivo diocesano

Propuesta institucional en verde, marfil y dorado. Los colores, radios y fuentes están en tokens.json; la implementación está en frontend/src/styles.css. El símbolo SVG propio es una propuesta gráfica y no reemplaza un escudo oficial.

[Tablero editable en Canva](https://canva.link/5mb8n52vn8f559u). Figma no está confirmado como conectado: no se ha creado un archivo allí. La aplicación no requiere cuentas de diseño para funcionar.

El informe 21 de la entrega documenta funciones, pruebas y la falta de revisión visual automática en navegador.
